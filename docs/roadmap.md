# 和 Fava 比，以及接下来做什么

[Fava](https://github.com/beancount/fava) 是 Beancount 官方的网页界面，功能全、偏电脑端，也能在网页上改账。
beanui 的定位不同：**只读，手机优先**；要改账，在交易详情点「复制给 AI 修改」，交给 AI 去改账本。
所以下面先列出两边的差别，再列打算补上的功能。

## beanui 有、Fava 没有（或要靠插件）的

- 手机布局，可以装成 PWA；深色模式跟随系统。
- 收付方和账户的品牌图标，科目和账户显示中文名（`name:`）。
- 信用卡额度：同一家银行的卡合并算额度，看已用、可用和使用率。
- 代管资金：替别人管的钱单独列出，不计入资产负债合计。
- 交易详情显示最后一次 git 提交；侧栏显示同步状态，有一个「同步」按钮。
- 流水把预记交易收进单独一组，同一天的交易按 `time:` 排序。
- 写了车次和开车时间的火车票画成车票，流水里写开车时间。

## 有，但比 Fava 弱的

| | beanui 现在 | Fava |
|---|---|---|
| 时间范围 | 本周、本月、上月、近三月、今年、全部，或某年、某月 | 任意表达式（季度、`year-1`、区间等） |
| 筛选 | 科目、分类、标签、收付方、关键词 | 过滤表达式，可组合元数据、链接 `^link` 等条件 |
| 图表 | 月度收支柱状图、净资产折线 | 还有树图、旭日图，区间可切换（日、周、月、季、年） |
| 科目 | 点科目跳到流水的筛选结果 | 每个科目有单独页面：余额走势、按区间的变动表 |
| 多币种 | 资产负债表按 `price` 换算；收支表只算主货币 | 可以按成本、按市值、按单位看，也能换算成任一币种 |
| 账本错误 | 只显示错误个数 | 有错误列表，能跳到出错的行 |

## 打算做

「更多」菜单里已经给下面这些留了入口：

**第二期**
- 试算平衡
- 持仓与成本：看投资的成本、市值和未实现盈亏
- 商品价格走势
- 事件
- 文档附件：看 `document` 指令关联的文件
- 错误列表

**第三期**
- BQL 查询，可以保存常用查询
- 源文件查看，能从交易跳到所在的行
- 导出 CSV

**零散的**
- 列出没认出品牌的收付方和笔数，方便补别名

## 不打算做的

- **在界面上记账、导入账单、上传文档。** 界面不写账本，这是设计上的取舍：
  改账走 AI 会话，账本仍是一个 git 仓库里的纯文本文件。
- **源文件编辑器**：就算做，也排在最后。

还没排进计划的有：预算（`custom "budget"`）、Fava 扩展、同时打开多本账本、多语言（目前只有中文）。
