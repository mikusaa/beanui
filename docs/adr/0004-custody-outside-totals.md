# 代管不计入资产负债合计，但留在净资产里

替别人管的钱记成成对的两棵树：`Assets:Custody:<代管人>:…`（钱放在哪）和 `Liabilities:Custody:<代管人>`（欠代管人多少）。
资产负债表把它们从资产、负债两边的合计里拿出来，按代管人各列一张卡，否则自己的资产和负债都会虚高，
看不出自己真有多少。

净资产仍按所有科目算。两边记平时差额为零，对净资产没有影响；没记平时差额留在净资产里，卡上提示，
净资产下面多写一行「含代管两边的差额」，而不是悄悄丢掉。哪一段算代管由 `config.yaml` 的 `custody` 定，
写 `null` 就当普通科目。
