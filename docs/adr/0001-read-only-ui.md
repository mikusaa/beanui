# 界面不写账本，改账交给 AI，同步只写请求

界面只读 `$LEDGER` 和它 include 的文件。要改账，在交易详情点「复制给 AI」，带上源文件和行号，到账本仓库的 AI 会话里改；
账本始终是 git 仓库里的纯文本，每次修改都是一次提交。「同步」按钮也不碰账本：后端只在 `$SYNC_DIR` 里写一个请求文件，
账本那边的 git-sync 看到请求后拉取，再写同步状态；界面等同步状态的时间不早于请求时间，就算同步完成。

## 考虑过的做法

- **像 Fava 那样在网页上改账**：要处理表单、并发写入和格式化，还会绕开 git 的审阅。用 AI 改账已经够快，
  手机上也不适合编辑分录。
- **后端直接跑 `git pull`**：账本就得以可写方式挂载，容器里还要放凭据。现在账本只读挂载，凭据只在 git-sync 那边。

## 后果

- 在界面上记账、导入账单、上传文档都不做（见 roadmap「不打算做的」）。
- 想在 NAS 上改账，就得在 NAS 上提交推送，再和主账本合并，界面本身不管。
