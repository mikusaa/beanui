# 交易类型只按分录判断，转账里的收益不算收入

每笔交易按分录分成支出、收入、转账三类（定义见术语表），不靠标签、元数据或收付方，账本不用为界面多写任何东西。
规则按先后是：有 Expenses 分录就是支出；没有支出、有 Income 分录，而且钱没在两个资金科目之间流动，就是收入；
其余都是转账。

代价是有些收益收支表看不到：卖基金时一起记的盈利、还款时的立减，记在转账里，就不算收入。
比如 `Assets:Investments:Fund` 出 1,000、`Assets:Bank:CMB` 进 1,050、`Income:Investment` 记 −50，这笔是转账，
那 50 不进收支表。我们接受这一点，因为把它们算进收入，收入里就会混进不是工资、也不是经常性收入的钱，
储蓄率会跟着买卖的时机跳。想单独看这些收益，以后从持仓与成本里看。

同一笔支出里顺带的优惠、返现也一样：交易仍算支出，金额取支出分录之和，优惠不另算收入。
