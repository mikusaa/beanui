# 账本约定写在 config.yaml，不写在 open 元数据上

分组怎么排、信用卡挂在哪个科目根下、银行代码叫什么、哪一段算代管，这些都由配置目录的 `config.yaml` 定，
`beanui/config.py` 给出默认值。

也可以在账本的 `open` 上写元数据来标（如 `group: 银行`），但那样每本账都要为界面改一遍，界面的分组一改，账本也要跟着改。
写成配置，账本只保留和界面无关也有意义的元数据：`name:`、`brand:`、额度。新加约定时照这个做：在 `Config` 里给默认值，
在 `config/config.yaml` 写上注释掉的示例，不在代码里写死某一本账的科目。
