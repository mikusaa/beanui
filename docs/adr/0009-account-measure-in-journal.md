# 只筛一个资金科目时，流水写这个科目的进出

流水平时写的是收支口径：支出写支出分录之和，平摊给别人时只算自己那份，有优惠时是原价。不筛的时候这样对，
可是筛了一张信用卡，想拿流水和账单一笔笔对的时候，行上的数就和卡上的对不上：一晚 965 的酒店，一半记在别人的应收里，
流水写 −482.50，卡上是 −965.00。

所以筛选里恰好一个资金科目时（也包括账户页点进来的父科目，比如按银行合并的信用卡；和分类一起筛也算），
流水换成账户口径：行上的数换成这个科目在这笔里的净变动，日合计和顶部合计换成它的流出、流入。只换行上的数、
不换合计的话，一天的数加起来又和合计对不上。交易类型、颜色、分类标签不变，这笔仍是一笔支出。
和收支口径的数不一样时，行上另起一行写「支出 482.50」，两边都看得到。

同时筛两个资金科目时不换：一笔在两个科目之间的转账，净变动没法只写一个数。只筛分类、标签、收付方时也不换。
合计只算这个科目最常用的币种，同收支只算主货币的道理一样，不按汇率换算。
