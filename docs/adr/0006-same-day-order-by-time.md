# 同一天的交易按 time: 排，不用 beancount 的顺序

beancount 把同一天的指令先按类型、再按行号排，行号不分文件。账本按文件拆开时（定期账单、分期各在一个文件，
日常交易按月一个文件），同一天的顺序就看文件碰巧排在哪，和实际先后无关。

流水在同一天里自己排：开户、余额断言放在交易前面（倒序显示时就落在当天最下面）；交易按 `time:` 元数据排。
没写时间的交易跟同一文件、同一天里前一笔有时间的，没有前一笔就跟后一笔；整个文件这一天都没写时间，就排在当天最后。
时间相同的保持原顺序。

记账时不强求每笔都写时间：只有需要排在别的交易前面的才写，比如月初零点扣的套餐费写 `time: "00:00"`。
