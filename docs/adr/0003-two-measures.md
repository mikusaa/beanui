# 收支只算主货币，资产负债按价格换算

两边的口径故意不一样。

- **收支**（概览、收支表、流水的合计）：只算到今天，预记不算；只算主货币，外币交易不进合计。
  收支要和同期比较，按交易当天的汇率换算会让同一笔钱在不同页面上数字不一样，不如干脆不算。
  外币消费很少，真有需要可以记成主货币。
- **资产负债**（账户页、资产负债表）：余额截至今天，未来日期的交易和价格都不用。主货币以外的持仓按当天或以前
  最近的 `price` 换算后计入净资产；没有价格的照列数量，注明「未计入」，不猜汇率。
  净资产要能和用 beancount 直接算的结果对上，所以不能漏掉外币持仓。

两边都只到今天，是因为账本里预记了分期和订阅，算进去，本月的数字就会被下个月的账单拉高。
