# 车票只看账本里写的元数据，界面不联网查时刻

火车票交易写齐 `train`、`from`、`to`、`depart` 四项元数据才画成车票，缺一项就照普通交易显示，不从摘要里猜车次和站名。
到站时刻、座位、手续费也只从元数据读。

考虑过界面联网查时刻表，没做：12306 没有公开接口，查到的也不会写回账本，同一张票每次打开都要再查一遍。
改成记账时由 AI 查好写进账本，账本就是唯一的数据来源，离线也能看。

退票照抄原票的元数据，金额是退回的钱，界面按金额方向判断是退票；手续费写在 `fee:` 上，原票 = 退回 + 手续费。
机票将来用同一套元数据，`train` 换成 `flight`。
